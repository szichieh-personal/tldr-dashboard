SilverTorch: turning retrieval pipelines into a single GPU model

Meta describes an “Index as Model” approach that folds embedding, ANN search, filtering, reranking, and scoring into a unified PyTorch model.

Why it matters: retrieval is becoming a differentiable, GPU-native workload — which changes tooling, cost models, and the interface for “context”.

A practical blueprint for agent evals: stable baselines, realistic messy data, and controlled comparisons across prompts/models/memory/search.
